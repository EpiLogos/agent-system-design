# Documentation Map

This is the working documentation surface for the QL Software Factory.

## `canon/`

- `QL-SOFTWARE-FACTORY-CONSTITUTIONAL-INDEX.md` — governing precedence map.
- `QL-SOFTWARE-FACTORY-ARCHITECTURE-SPEC.md` — canonical architecture specification.
- `QL-SOFTWARE-FACTORY-PRIMITIVE-RELATIONS.md` — canonical primitive/relations specification.
- `QL-SOFTWARE-FACTORY-WORKCELL-MODULE-SPEC.md` — Workcell canonical companion.
- `QL-SOFTWARE-FACTORY-DEEP-QL-INTEGRATION-FOUNDATIONS.md` — deep QL integration foundations.
- `EXECUTION-INTELLIGENCE-INTEGRATION.md` — current-design cross-map amendment making the situated execution seam explicit; subordinate to the Constitutional Index.
- `wayfinders/` — harmonised architectural Claim-sets.

## `program/`

The root pre-ticket programme and executable amendments. GitHub Issues are generated as a projection of this material; Issues are not the canonical Run Map or Factory ontology.

## `research/`

Comparative evidence and claim-sets. Location here means **no architectural authority by presence**. Research must be explicitly integrated into canon/programme material before implementation treats it as a determination.

## `seed-docs/` at repository root

The initial collected snapshot is retained for provenance/history. Where a working `docs/` copy or amendment exists, `docs/` is the implementation-facing location; authority is still determined by the Constitutional Index and determination status, not directory location alone.

# Part XVII — Acceptance cases

## 69. Identity and ownership

- refracting an Agent does not create a new Agent identity;
- refracting a Claim does not replace the Claim;
- a QL reading always retains the original target Ref;
- the module cannot mutate Project/Run/Action truth without an explicit client-side operation;
- client-specific software nouns are not copied into the canonical lens registry as lens definitions.

## 70. Provider negotiation

- a client can discover exactly which forms/lenses/operators are supported;
- unsupported extensions fail explicitly;
- a provider supporting `refract` is not assumed to support conjugation;
- provider/version provenance survives storage/replay.

## 71. No-QL parity

- AIKit ordinary resolution passes with no QL provider;
- Factory ordinary Run/Candidate/Claim/Recognition paths pass with no QL provider;
- Workcell materialisation passes with no QL provider;
- classic agent runtimes pass with no QL provider;
- fixture providers can reproduce deterministic integration tests.

## 72. MEF integrity

- all twelve lenses remain addressable;
- a software role binding does not rename a lens;
- lenses can be applied to multiple primitive types;
- several independent lens readings can coexist;
- synthesis retains source readings and unresolved difference;
- no rule requires twelve agents or twelve stages merely because twelve lenses exist.

## 73. Operational parity

- a feature labelled QL-operational has a documented baseline and observable difference;
- decorative labels alone do not satisfy parity tests;
- QL-runtime recurrence tests prove semantic difference from classic loop closure;
- semantic refraction results are attributable and replayable to their provider/input revisions.

## 74. Semantic honesty

- ambiguous `locate` results can remain ambiguous;
- a semantic provider can return insufficient information;
- stochastic readings are not labelled deterministic;
- research extensions are not silently promoted into stable contracts;
- old readings remain interpretable after provider upgrades.

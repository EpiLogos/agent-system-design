# Computers for developers and agents

Durable Sandboxes that are fast, secure, and sharable.

## API first

`ssh exe.dev` to see for yourself.

A built-in web agent to build apps.

### It’s just a computer

You buy a pool of CPU, RAM, and disk. You get as many VMs as you like.

SSH in, you are root, you have `apt` and `systemd`. Your servers are persistent, private by default, and shareable with [IAM](/docs/proxy).

You have a web agent too, [Shelley](/docs/shelley/intro), for coding.
